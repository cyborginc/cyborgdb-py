# SDK sync plans

Porting plans generated by [`/sync-sdks`](../.claude/commands/sync-sdks.md), one per Python SDK change that needs to be mirrored into `cyborgdb-js` and / or `cyborgdb-go`.

## Workflow

1. Python SDK change ships in `cyborgdb-py` (PR merged or close to it).
2. Run `/sync-sdks` (optionally `/sync-sdks --pr <num>`) on the source branch.
3. Skill writes `<id>/js.md` and `<id>/go.md` here, summarizing public-surface deltas + the equivalent target-language translation.
4. Plan files get reviewed via PR (just like any other change in this repo).
5. After approval, the JS / Go SDK owners implement the changes manually in their respective repos, using the plan as a checklist.
6. When implemented, update the plan's `status:` frontmatter field (`draft` → `reviewed` → `implemented` → `obsolete`) and update the row below.
